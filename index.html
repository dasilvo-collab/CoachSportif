Comment lire ces scores ?

Ce sont des indices de pilotage, pas des garanties scientifiques. Ils évoluent selon la régularité, les séances clés, la progression, la fatigue et la proximité de l'épreuve. Pour le Cervin, le score mesure votre niveau de préparation physique. La météo, les conditions et la décision du guide restent hors modèle.

Données

Vos données restent dans le navigateur de cet appareil. Téléchargez régulièrement une sauvegarde complète JSON : elle permet de restaurer l’historique, les brouillons, les objectifs, les prescriptions, les réglages et les indicateurs dans toute future version de CAP.

Protection de votre historique
1. « Sauvegarde complète » = fichier de restauration à conserver et à me transmettre lors d’une future évolution.
2. « Historique lisible » = export JSON centré sur les séances, utile pour audit mais non destiné à restaurer seul toute l’application.
3. Après installation d’une nouvelle version, utilisez « Restaurer une sauvegarde complète » : CAP fusionne les données sauvegardées avec le nouveau schéma.
